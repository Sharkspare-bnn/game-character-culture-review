# 命名检查方法

核实日期：2026-09（初稿）

## 一、逐语言拆解

对每个语言版本的名字（中文名、英文名、日文名、韩文名，以及拼音或罗马字转写）都做以下检查：

1. **原意**：这个名字在它原本的语言里是什么意思、由哪些字或词根组成
2. **读音转写**：在目标语言里会怎么读、怎么写
   - 日文：片假名写法，拆成音节后看是否组成已有词语
   - 韩文：韩文拼写，看是否与已有词语同音
   - 英文：玩家会怎么读（按英文拼读习惯），是否形成已有单词或俚语
3. **谐音与近音**：检查是否谐音以下几类词：
   - 粗俗词、性相关词语
   - 疾病、死亡、不吉利的词
   - 宗教用语、神圣称号
   - 在目标市场常见的族群蔑称
   - 与当地政治人物、罪犯、灾难相关的词
4. **称号与技能名**：同样检查称号、技能名、武器名、皮肤系列名

拿不准时标"需确认"，交给母语者核查。不要用模型对某门语言俚语的记忆下肯定结论。

## 二、撞名检索

有联网搜索工具时，按以下范围检索；把检索词和主要结果写进报告的风险定位表：

| 检索范围 | 检索词示例 |
| --- | --- |
| 当地知名游戏、动画、漫画角色 | 名字 + 角色 / キャラ / 캐릭터 |
| 当地知名品牌、商标 | 名字 + 品牌 / ブランド / 브랜드 |
| 真实人物（艺人、政治人物、新闻人物） | 名字（原文） |
| 同品类竞品 | 名字 + 竞品游戏名 |

没有搜索工具时，写明"未能检索撞名，需人工核查"。撞名只作风险提示，是否构成商标或著作权问题交给法务。

## 三、名字与原型的自洽性

- 使用某个文化的名字时，角色是否体现了该文化的特征？只借名字、不体现文化，容易被批评为"挪用"
- 使用神名、圣名、历史人物名时，角色定位是否与原型的含义冲突（例如用和平之神的名字命名一个嗜杀角色）
- 同一游戏里是否已有同源、同音的名字，会不会造成混淆

## 四、给出备选

需要改名时，提供 2–3 个备选名字，每个都说明：
- 保留了原名的哪层意思
- 在各目标语言里的读法
- 已做过哪些检查、还需人工核查什么
